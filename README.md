# МобилМаш

Сайт компании «МобилМаш» — складская техника для бизнеса.

## Структура

| Файл | Описание |
|------|----------|
| `index.html` | Разметка |
| `styles.css` | Стили |
| `app.js` | Логика (каталог, корзина, слайдер, формы) |
| `старый код.txt` | Как получить версию до оптимизации |

## Что оптимизировано

- CSS и JS вынесены в отдельные файлы
- Убрана логика цен (сортировка/фильтр по цене, суммы в ₽)
- Корзина показывает **количество** товаров
- `background-attachment: fixed` только на десктопе
- `preconnect` / `dns-prefetch` для шрифтов и CDN
- `loading="lazy"` у изображений
- Passive scroll-listener для кнопки «наверх»
- Сортировка по названию (А–Я / Я–А)
