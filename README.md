# МобилМаш

Сайт компании «МобилМаш» — складская техника для бизнеса.

## Версии

- `index.html` — **текущая оптимизированная** версия
- `старый код.txt` — исходная версия до оптимизации (полный HTML)

## Что оптимизировано

- Убрана логика цен (сортировка/фильтр по цене, суммы в корзине)
- Корзина показывает количество товаров, без ₽
- `background-attachment: fixed` только на десктопе (на мобильных — scroll, меньше лагов)
- `preconnect` / `dns-prefetch` для шрифтов и CDN
- `loading="lazy"` для изображений
- Passive scroll-listener для кнопки «наверх»
- Лёгкие media-query для hover-эффектов на мобильных

Дизайн и основной функционал сохранены.
