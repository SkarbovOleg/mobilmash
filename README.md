# МобилМаш — сайт компании

Статический сайт (один HTML-файл, **без сборки**) для компании «МобилМаш» — нефтегазовое и буровое оборудование, инжиниринг и сервис.

---

## Быстрый старт

1. Откройте `index.html` в браузере — сайт сразу работает.
2. Никакой сборки, установки зависимостей или сервера не нужно.
3. Используются внешние CDN: **Font Awesome 6** (иконки) и **Google Fonts** (шрифты) — нужен интернет.

---

## Как устроен index.html

Файл состоит из трёх частей:

1. **`<style>`** — все стили (в начале файла).
2. **HTML-разметка** — шапка, hero-слайдер, каталог, события, блог, о компании, контакты, футер.
3. **`<script>`** — вся логика: данные, рендер, обработчики (в конце файла).

### Секции сайта

| Якорь | Секция |
|---|---|
| `#home` | Главная (hero-слайдер, преимущества, лента ВК) |
| `#catalog` | Каталог: боковое меню + карточки товаров |
| `#selection` | Подбор техники (форма) |
| `#events` | События / выставки |
| `#blog` | Полезные статьи |
| `#about` | О компании + сертификаты |
| `#contact` | Контакты + форма обратной связи |

## Каталог

### Категории (`data-cat` в боковом меню)

| `data-cat` | Группа в меню | Что внутри |
|---|---|---|
| `буровые` | **Буровые установки** | 20 моделей (УРБ 3А3, БА 15, …, МБС 250) |
| `нефтегаз` | **Нефтегазопромысловое оборудование и инструменты** | роторы, захваты, установки |
| `товары` | (в «Все товары») | складская техника: погрузчик, штабелёр и т.д. |
| `прочие` | **Узлы и запасные части** | запчасти, масло, чехол |
| `услуги` | **Сервис** | техобслуживание, ремонт гидравлики, обучение |
| `проект` | **Услуги** | Минпромторг, проектирование по ТЗ, изготовление по КД, литьё |

### Как добавить / изменить товар

Все товары лежат в массиве **`defaultProducts`** (в `<script>`, ищем `const defaultProducts = [`).

Пример:

```js
{
  id: 108,
  name: "Ротор буровой Р-410",
  category: "нефтегаз",
  type: "Роторы",
  price: 0,
  imageData: "img/rotor-r410.png",
  subtitle: "механическим",
  specs: [
    "Диаметр проходного отверстия стола: 410 мм",
    "Максимальный крутящий момент: 8000 Н·м"
  ],
  description: "Буровой ротор для бурения и ремонта скважин."
}
```

#### Поля товара

| Поле | Обязательно | Что делает |
|---|---|---|
| `id` | ✅ | уникальный номер (не повторять!) |
| `name` | ✅ | название в карточке |
| `category` | ✅ | `буровые` / `нефтегаз` / `товары` / `прочие` / `услуги` / `проект` |
| `type` | ✅ | подпись над названием (Роторы, Захваты, Услуги…) |
| `price` | — | цена (0 = «по запросу») |
| `imageData` | — | путь к фото: `img/файл.png` или URL |
| `icon` | — | иконка Font Awesome, напр. `fa-gear`. **Если задана — фото не показывается!** |
| `subtitle` | — | красная подпись под названием |
| `specs` | — | массив характеристик (в карточке и в быстром просмотре) |
| `description` | — | краткое описание |
| `features` | — | теги-преимущества (для услуг) |
| `model` | — | модель для вкладок буровых установок |

### Куда класть фото

1. Положите файл в `img/`, например `img/rotor-r410.png`.
2. В товаре укажите `imageData: "img/rotor-r410.png"`.
3. ⚠️ **Если у товара задан `icon` — фото НЕ показывается.** Уберите `icon`, чтобы показывать фото.

### Вкладки буровых установок

- Ряд кнопок (УРБ 3А3, БА 15, …) показывается **только** в группе «Буровые установки».
- Клик по вкладке фильтрует каталог по полю **`model`** (точное совпадение).
- «ВСЕ БУРОВЫЕ УСТАНОВКИ» — сбрасывает фильтр, показывает все установки.

### Пагинация и поиск

- `itemsPerPage = 6` — карточек на странице (меняется в начале скрипта).
- Поиск — по названию и типу.
- Фильтры по цене — `priceMin` / `priceMax`.

### Быстрый просмотр

- Кнопка «Быстрый просмотр» на карточке открывает окно (`#quickViewModal`).
- Внутри: фото/иконка, тип, название, `subtitle`, описание, `features`, `specs`, кнопка **«Связаться с нами»** (закрывает окно и ведёт к контактам).

## Сертификаты

- PDF лежат в `certs/`.
- Карточки — в секции «О компании», блок `.certificates-section` (ищем `class="certificates-grid"`).

Добавить сертификат:

1. Положить PDF в `certs/`, например `certs/new-cert.pdf`.
2. Добавить карточку:

```html
<a class="cert" href="certs/new-cert.pdf" target="_blank" rel="noopener">
    <i class="fas fa-file-pdf"></i>
    <h4>Название сертификата</h4>
    <p>Действует до …</p>
    <span class="cert-link">Открыть PDF</span>
</a>
```

## ⚠️ Важно: localStorage

Сайт сохраняет данные в браузере (`localStorage`):

`mobilmash_products`, `mobilmash_events`, `mobilmash_logo`, `mobilmash_favorites`, `mobilmash_compare`, `mobilmash_cart`.

- Если данные менялись через админку/браузер — используется **сохранённая** версия, а не `defaultProducts`.
- Сбросить: DevTools → Application → Local Storage → удалить ключи, или открыть сайт в приватном окне.
- При загрузке иконки/характеристики подтягиваются из `defaultProducts` даже к сохранённым товарам.
