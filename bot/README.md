# MAX-бот для заявок МобилМаш

Бот принимает заявки с сайта (кнопка «Заказать обратный звонок») и отправляет их в вашу **группу MAX** (или менеджеру лично).

---

## 1. Что нужно заранее

Создавать ботов в MAX могут только **юрлица, ИП и самозанятые — резиденты РФ**.
Нужен подключённый и **верифицированный профиль** на платформе MAX для партнёров.

1. Зайдите на https://business.max.ru/self
2. Создайте профиль организации / ИП / самозанятого и пройдите верификацию.

> Альтернатива: мини-приложение «MAX для бизнеса» — https://max.ru/business_bot?startapp

---

## 2. Создать бота

1. В профиле на платформе откройте раздел **«Чат-боты»** → **«Создать»**.
2. Заполните карточку:
   - **Логотип** — 500×500 px, до 5 МБ, `.jpg/.png`;
   - **Название** — 1–59 символов;
   - **Описание** — до 200 символов;
   - **Никнейм** — создаётся автоматически: `idИНН_bot` (для ИП/юрлиц) или `se(orgid)_bot` (самозанятые). Изменить нельзя.
3. Нажмите **«Создать»** → бот уйдёт на модерацию (до 48 часов по рабочим дням).

---

## 3. Получить токен

После успешной модерации:
1. Откройте карточку бота на платформе → **«Настройки»**.
2. Найдите раздел **«Токен бота»** и скопируйте его.
3. Храните токен в секрете — он даёт полный доступ к боту.

---

## 4. Добавить бота в группу MAX

1. Откройте вашу группу в MAX.
2. Название группы → **«Участники»** → **«Добавить участников»**.
3. Найдите бота по никнейму (`idИНН_bot`) и добавьте.
4. Бот теперь может писать в группу.

> Чтобы бот знал, куда писать, нужен **id группы**. Он появится в консоли бота (`bot.js`), когда в группе кто-то напишет сообщение, или его можно получить через API.

---

## 5. Настроить и запустить бота

1. В папке `bot/` скопируйте `.env.example` → `.env`:
   ```
   BOT_TOKEN=токен_из_шага_3
   MANAGER_ID=id_группы_или_менеджера
   ```
2. Установите зависимости и запустите:
   ```bash
   cd bot
   npm install
   node bot.js
   ```

---

## 6. Подключить к сайту

В `index.html` найдите:
```js
var MAX_BOT_NAME = '';
```
и впишите никнейм бота (без `@`), например:
```js
var MAX_BOT_NAME = 'id7701234567_bot';
```

Теперь кнопка «Заказать обратный звонок» открывает чат с ботом
(`https://max.ru/<ник>?start=<текст заявки>`), а бот пересылает заявку в группу/менеджеру.

---

## 7. Где держать бота

Бот должен работать постоянно:
- VPS (Node.js 18+);
- Railway / Render (бесплатные тарифы);
- либо ваш ПК (пока он включён).
