# MAX-бот для заявок МобилМаш

Бот принимает заявки с сайта (кнопка «Заказать обратный звонок») и пересылает их менеджеру в MAX.

---

## 1. Создать бота в MAX

1. Откройте MAX и найдите диалог с **@MasterBot** (Мастер ботов).
2. Нажмите «Создать бота» → укажите имя, описание, аватар.
3. MasterBot пришлёт **токен** — сохраните его (это `BOT_TOKEN`).

> Для создания бота нужен профиль партнёра MAX (юрлицо/ИП/самозанятый, резидент РФ):
> https://dev.max.ru/docs/chatbots/bots-create/create/

---

## 2. Настроить и запустить

1. Скопируйте `.env.example` → `.env` и заполните:
   - `BOT_TOKEN` — токен от @MasterBot;
   - `MANAGER_ID` — id менеджера в MAX (см. ниже).
2. Установите зависимости и запустите:

```bash
cd bot
npm install
node bot.js
```

### Где взять `MANAGER_ID`

Менеджер пишет боту любое сообщение — бот записывает его id в консоль (см. `bot.js`).
Либо id можно посмотреть в профиле менеджера в MAX.

---

## 3. Подключить к сайту

В `index.html` найдите:

```js
var MAX_BOT_NAME = '';
```

и впишите ник бота (без `@`), например:

```js
var MAX_BOT_NAME = 'mobilmash_bot';
```

После этого кнопка «Заказать обратный звонок» открывает чат с ботом
по ссылке `https://max.ru/<бот>?start=<текст заявки>`, а бот пересылает заявку менеджеру.

---

## 4. Где держать бота

Бот должен работать постоянно, поэтому нужен хостинг:
- VPS (любой, Node.js 18+);
- Railway / Render (бесплатные тарифы);
- либо ваш ПК (пока он включён).
