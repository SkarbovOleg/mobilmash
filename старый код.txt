Старая версия сайта (до оптимизации)
=====================================

Полный исходный index.html (единый файл ~100 KB) сохранён в истории git.

Как получить:
1. Открой: https://github.com/SkarbovOleg/mobilmash/blob/b1c7ff3f14ce3c0d4dc934d79a86c25195a850e9/index.html
2. Или локально:
   git show b1c7ff3f14ce3c0d4dc934d79a86c25195a850e9:index.html > "старый код full.html"

Коммит до оптимизации (последний со старым монолитным index.html):
b1c7ff3f14ce3c0d4dc934d79a86c25195a850e9

Что изменилось в новой версии
-----------------------------
- CSS вынесен в styles.css, JS — в app.js (быстрее грузится, кэшируется отдельно)
- Убрана логика цен (сортировка/фильтр по цене, суммы в ₽)
- Корзина показывает количество товаров
- background-attachment: fixed только на десктопе
- preconnect / dns-prefetch для шрифтов и CDN
- loading="lazy" у картинок
- passive scroll-listener для кнопки «наверх»
- Сортировка по названию (А–Я / Я–А)

Дизайн и основной функционал сохранены.
